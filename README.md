## The entry

> The lighthouse keeper lit nothing tonight.

Six words, 42 characters. A keeper whose one job is to light the
lamp lights nothing tonight — and the reader is left to fill in why:
gone, dead, or done with it on purpose. A whole life of duty, and
one night it stops.

## How it works

`main.py` (Python 3.13, stdlib only, no network, no clock, no
randomness) writes that six-word story to `/output/entry.txt`. The
same bytes every run.

```sh
python3 main.py
cat /output/entry.txt
```
